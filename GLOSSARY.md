# Термины jirawarrior-tui

## Language

**jirawarrior-tui (Jira TUI)**:
Терминальное приложение для read-only обзора своих незавершённых задач в Jira Server/Data Center: текущего спринта и остальных задач. Не изменяет данные Jira; название не обозначает интеграцию с Taskwarrior.
_Avoid_: Редактор задач Jira, командный дашборд

**Статус задачи Jira**:
Текущий этап задачи в рабочем процессе Jira, например «Открыта», «В работе» или «На проверке». Не связан с локальными метками просмотра задачи.
_Avoid_: Метка просмотра, категория статуса

**Группа по статусу**:
Задачи с одинаковым названием статуса Jira в пределах одной области обзора. Задачи из разных проектов входят в одну группу, если названия их статусов совпадают.
_Avoid_: Категория статуса, группа по меткам просмотра

**Локальные метки просмотра**:
Отметки `NEW` и непросмотренных комментариев в Jira TUI, отражающие наблюдение и открытие задач через этот инструмент. Не означают прочтение задачи человеком и не синхронизируются с просмотром в других приложениях или на других устройствах.
_Avoid_: Статус задачи Jira, серверный статус прочтения

**Новая задача**:
Задача Jira, впервые появившаяся в локальном обзоре после его начального заполнения и ещё не подтверждённая открытием через Jira TUI. Дата создания задачи в Jira не определяет её новизну для обзора.
_Avoid_: Недавно созданная задача, новая задача команды

**Непросмотренный комментарий**:
Доступный чужой комментарий, появившийся после исходного наблюдения задачи и ещё не подтверждённый открытием задачи из показанного обзора через Jira TUI. Собственные комментарии и редактирование уже известного комментария к этому понятию не относятся.
_Avoid_: Непрочитанный комментарий в Jira, любое изменение задачи

**Сессия обзора**:
Работа одного открытого Jira TUI с фиксированным экземпляром Jira и учётной записью, охватывающая обновление обзора и локальное наблюдение задач до выхода из приложения. Не является серверной сессией Jira или фоновым наблюдением после выхода.
_Avoid_: Серверная сессия Jira, фоновый мониторинг
