# Термины jirawarrior-tui

## Language

**jirawarrior-tui (Jira TUI)**:
Терминальное приложение для обзора своих незавершённых задач в Jira Server/Data Center: по текущему спринту и остальным задачам либо по эпикам, с ограниченной возможностью добавления выбранной обычной задачи в активный спринт. Не является общим редактором Jira; название не обозначает интеграцию с Taskwarrior.
_Avoid_: Редактор задач Jira, командный дашборд

**Открытая задача обзора**:
Задача Jira, назначенная текущему пользователю, не имеющая resolution и не находящаяся в статусе `Verifying` (без учёта регистра). Остальные названия статусов не ограничивают её включение в обзор.
_Avoid_: Любая незавершённая задача команды, задача только в статусе «Открыта»

**Эпик**:
Задача Jira Software, объединяющая связанные тикеты, включая подзадачи через их родительские тикеты. Исполнитель эпика и наличие у него resolution не определяют исполнителей и открытость относящихся к нему тикетов.
_Avoid_: Спринт, проект Jira, группа по статусу

**Режим эпиков**:
Представление открытых задач обзора по эпикам: каждый эпик объединяет относящиеся к нему задачи независимо от их спринта. Задачи без эпика в это представление не входят.
_Avoid_: Командный дашборд, группировка по спринту

**Представление обзора**:
Показ задач из последнего успешного обзора по текущему спринту и остальным задачам либо в режиме эпиков, с локальными метками просмотра и сохранением выбранной задачи при обновлении или смене режима, пока она доступна в новом представлении. Не является новой загрузкой Jira и не изменяет историю просмотра само по себе.
_Avoid_: Сессия обзора, серверная выборка, снимок Jira

**Статус задачи Jira**:
Текущий этап задачи в рабочем процессе Jira, например «Открыта», «В работе» или «На проверке». Не связан с локальными метками просмотра задачи.
_Avoid_: Метка просмотра, категория статуса

**Группа по статусу**:
Задачи с одинаковым названием статуса Jira в пределах одной области обзора либо одного эпика и одного приоритета локальных меток просмотра. Задачи из разных проектов входят в одну группу, если названия их статусов совпадают.
_Avoid_: Категория статуса, группа по меткам просмотра

**Локальные метки просмотра**:
Искусственные отметки `NEW` (новая задача) и `Comment +N` (число непросмотренных комментариев) в Jira TUI, отражающие наблюдение и открытие задач через этот инструмент. Не означают прочтение задачи человеком и не синхронизируются с просмотром в других приложениях или на других устройствах.
_Avoid_: Статус задачи Jira, серверный статус прочтения

**Новая задача**:
Задача Jira, впервые появившаяся в локальном обзоре после его начального заполнения и ещё не подтверждённая открытием через Jira TUI. Дата создания задачи в Jira не определяет её новизну для обзора.
_Avoid_: Недавно созданная задача, новая задача команды

**Непросмотренный комментарий**:
Доступный чужой комментарий, появившийся после исходного наблюдения задачи и ещё не подтверждённый открытием задачи из показанного обзора через Jira TUI. Собственные комментарии и редактирование уже известного комментария к этому понятию не относятся.
_Avoid_: Непрочитанный комментарий в Jira, любое изменение задачи

**Сессия обзора**:
Работа одного открытого Jira TUI с фиксированным экземпляром Jira и учётной записью, охватывающая обновление обзора и локальное наблюдение задач до выхода из приложения. Не является серверной сессией Jira или фоновым наблюдением после выхода.
_Avoid_: Серверная сессия Jira, фоновый мониторинг
