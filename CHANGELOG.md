# Выпуски

## Не выпущено

- Подпись переключателя `e` сокращена до «Эпики». Спринты с именем вида
  `DEMO-2026-W43` отображаются в заголовке как «43-я неделя»; остальные имена
  сохраняются вместе с ID.
- Обычные области используют общую ширину колонок: статусы выровнены независимо
  от длины ключей, меток и названий. Ширины пересчитываются после обновлений,
  включая уменьшение после исчезновения длинных строк.
- Эпики скрыты из обычных областей. `e` (также кириллическая `е`) переключает
  единый список эпиков с собственными открытыми тикетами и возвращает обычный вид.
  Поддержаны пустые свои, чужие/закрытые родительские эпики и подзадачи через
  родителя; контекстные эпики открываются без создания локальных меток.
- Основная команда переименована в `jirawarrior`, добавлен короткий алиас `jw`.
  Команда `jira-overview` больше не устанавливается; вызывающие её скрипты
  и ранее скопированные Taskfile нужно обновить.
- Репозиторные Go Task-обёртки запускают `jirawarrior`; их имена сохранены.
- Python-модуль `jira_overview`, пути TOML/состояния `jira-overview`, переменные
  окружения и формат локальных меток сохранены, миграция данных не нужна.

## 0.1.0

Первый самостоятельный публичный выпуск **jirawarrior-tui**.

- Read-only обзор собственных незавершённых задач Jira Server/Data Center:
  текущий спринт и остальные задачи, обновление, открытие в браузере.
- Локальные `NEW`/непросмотренные комментарии с сохранением между запусками.
- Сохранены `jira-overview`, пути конфигурации/состояния и формат профиля v1.
- Установка через uv из Git-тега `v0.1.0`, без checkout ossetup.
- Необязательные `t jira` / `t jira:check` вызывают установленную команду.
- Поддерживается только macOS; Jira Cloud, запись в Jira, PyPI/Homebrew,
  фоновые службы и интеграция с Taskwarrior в выпуск не входят.
- MIT для собственного кода, сохранённая атрибуция и перечень лицензий зависимостей.

Проверки кандидата и опубликованного тега фиксируются в GitHub Release
и итоговом комментарии `aprudkin/ossetup#14`. Синтетические тесты не заменяют
живую read-only приёмку и не доказывают чтение страницы человеком.
