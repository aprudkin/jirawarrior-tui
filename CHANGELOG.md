# Выпуски

## 0.1.0

Первый самостоятельный публичный выпуск **jirawarrior-tui**.

- Read-only обзор собственных незавершённых задач Jira Server/Data Center:
  текущий спринт и остальные задачи, обновление, открытие в браузере.
- Локальные `NEW`/непросмотренные комментарии с сохранением между запусками.
- Сохранены `jira-overview`, пути конфигурации/состояния и формат профиля v1.
- Установка через uv из Git-тега `v0.1.0`, без checkout ossetup.
- Необязательные `t jira` / `t jira:check` вызывают установленную команду.
- Поддерживается только macOS; Jira Cloud, запись в Jira, PyPI/Homebrew,
  фоновые службы и интеграция с Taskwarrior в выпуск не входят.
- MIT для собственного кода, сохранённая атрибуция и перечень лицензий зависимостей.

Проверки кандидата и опубликованного тега фиксируются в GitHub Release
и итоговом комментарии `aprudkin/ossetup#14`. Синтетические тесты не заменяют
живую read-only приёмку и не доказывают чтение страницы человеком.
