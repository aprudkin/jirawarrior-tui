# Triage labels

Словарь ролей для установленного skill `triage`.
Перед классификацией читай этот mapping и актуальные labels задачи.

| Роль | Метка GitHub | Смысл |
| --- | --- | --- |
| needs-triage | `needs-triage` | Требуется оценка сопровождающего |
| needs-info | `needs-info` | Ожидание дополнительных сведений |
| ready-for-agent | `ready-for-agent` | Задача специфицирована для исполнения агентом |
| ready-for-human | `ready-for-human` | Нужны человеческие решения или доступ |
| wontfix | `wontfix` | Работа не планируется |

Категории skill: `bug` → `bug`, `enhancement` → `enhancement`.
После triage задача имеет одну категорию и одно triage-состояние.
При конфликте состояний сначала запроси решение сопровождающего.
Остальные метки (например, `documentation`) сохраняются.

`in-progress` — отдельный статус исполнения, не шестое triage-состояние;
его жизненный цикл описан в [issue-tracker.md](issue-tracker.md).
Обычная работа по issue не запускает triage автоматически.
PR не входят в автоматическую область triage.

При сверке сохраняй ID, цвет и описание существующих меток; создавай только
подтверждённо отсутствующие. Установка skill и mapping не являются разрешением
переклассифицировать весь backlog.
